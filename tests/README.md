# AI识别测试脚本

这个目录包含用于测试AI识别功能的脚本。

## 测试脚本说明

### `test_ai_recognition.py`

AI识别测试的主要脚本，支持两种模式：

#### 1. 手动模式 (Manual Mode)
用于初期测试和模型选择，流程如下：
1. 分析本地动漫文件
2. 从TMDB获取动漫信息
3. 生成完整的prompt
4. 输出prompt供用户复制
5. 用户将prompt发送给LLM
6. 用户将LLM响应粘贴回程序
7. 程序解析和验证响应

**使用方法：**
```bash
python tests/test_ai_recognition.py --mode manual --path "/path/to/anime"
# 可选：强制开启或关闭JSON模式进行测试
python tests/test_ai_recognition.py --mode manual --path "/path/to/anime" --json_mode true
```

**适用场景：**
- 测试不同的LLM模型效果
- 调试prompt内容
- 验证JSON结构
- 不需要配置API的情况

#### 2. 自动模式 (Auto Mode)
完整的AI识别流程，但不实际移动文件：
1. 检查AI和TMDB配置
2. 分析本地动漫文件
3. 自动调用AI API
4. 显示分析结果
5. 模拟文件操作（不实际执行）

**使用方法：**
```bash
python tests/test_ai_recognition.py --mode auto --path "/path/to/anime"
# 可选：强制开启或关闭JSON模式进行测试
python tests/test_ai_recognition.py --mode auto --path "/path/to/anime" --json_mode false
```

**适用场景：**
- 测试完整的AI识别流程
- 验证配置是否正确
- 预览文件重命名结果
- 生产环境前的最终测试

## 输出文件

### 手动模式输出
- `ai_test_result.json`: 包含测试结果和原始LLM响应

### 自动模式输出
- `ai_auto_test_result.json`: 包含完整的分析过程和结果

## 配置要求

### 手动模式
- 仅需要TMDB API密钥

### 自动模式
- TMDB API密钥
- AI API密钥
- AI API地址
- AI模型名称
- AI功能启用状态

## 注意事项

1. **路径格式**: 确保提供的路径存在且包含视频文件
2. **配置检查**: 自动模式会检查所有必要的配置项
3. **网络连接**: 需要能够访问TMDB API和AI API
4. **文件权限**: 确保有读取视频文件的权限
5. **依赖安装**: 确保已安装`tinytag`等依赖

## 故障排除

### 常见错误
- `未配置TMDB API密钥`: 检查config.json中的api_key
- `AI功能未启用`: 检查ai_enabled配置
- `未找到视频文件`: 确认路径正确且包含支持的视频格式
- `网络错误`: 检查网络连接和API地址

### 调试建议
1. 先使用手动模式测试prompt生成
2. 验证TMDB搜索结果是否正确
3. 检查视频文件分析结果
4. 逐步测试AI API连接
